# Divine Core — project page

Source for <https://nikolasgkou.github.io/divine-core-docs/>.

A single-page technical overview of **Divine Core**: a control plane for Codex
and Claude with recorded permissions, isolated Git worktrees, source-bound
builder verification, and scoped OpenRewrite recipe execution.

The page covers the system architecture, the task lifecycle and its evidence
gate, how verification is frozen before launch and bound to a source digest,
how a worker's effective tool policy is composed and recorded, the fixed review
checklist, and how semantic recipes move from analysis to preview and verified
application.

This repository contains the published page only. The implementation lives in a
separate, private repository.
